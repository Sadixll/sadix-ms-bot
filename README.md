# 😈 Sadix MS Bot

Telegram-бот для скачивания видео из YouTube, TikTok, Instagram, Twitter, VK и других сетей.

## Функции
- 🎬 Скачивание из всех соцсетей (yt-dlp)
- 🔓 Работа с защищёнными видео
- 🆓 Бесплатно: 5 видео/день
- 💎 Премиум: бесконечные скачивания

## Активация премиума
`/premium Sadixll`

## Деплой на Render
1. Environment: `BOT_TOKEN`, `YOUTUBE_COOKIES` (base64)
2. Build: `pip install -r requirements.txt`
3. Start: `python main.py`
